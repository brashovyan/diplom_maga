# Магистерская диссертация 2026

Разработка программных средств для управления многоколёсным всенаправленным роботом и его имитационной моделью в среде CoppeliaSim

В двух словах - в симуляторе рисуешь путь, виртуальный робот по нему проезжает, запоминает его, отправляет на реального робота, реальный робот его воспроизводит.

Кроме этого есть возможность управления роботом в реальном времени при помощи виртуального джойстика на сайте и отправка команд из Python

Все бумажки лежат в папке diplom

OffRadDrone - прошивка

robot_control - управление джойстиком

OffRoadDrone_06_04_2024.ttt - CoppeliaSim (разрабытвалось на версии 4.8.0)

grapsh.py - рисование графиков по csv логам (pandas, matplotlib, numpy)

send.py - скрипт управления роботом простыми командами (любой питон без библиотек)

udp.py - тестовый скрипт для прослушки мультикаст адреса (посмотреть че приходит) (любой питон без библиотек)

# Как прошивать робота

На момент разработки Arduino Ide 2.3.6

Какие библиотеки качать?

ESPAsyncWebServer от ESP32async

AsyncTCP от ESP32async

SQLite3ESP32 от Arundale Ramanathan

Остальные библиотеки (WiFi.h, SD.h, SPI.h, FS.h, WebServer.h, Ticker.h) входят в состав пакета ESP32 и не требуют отдельной установки.


Добавить ссылку на дополнительные платы:

Файл → Настройки

В поле Дополнительные ссылки для менеджера плат добавить: https://espressif.github.io/arduino-esp32/package_esp32_index.json


Установить пакет ESP32:

Инструменты → Плата → Менеджер плат...

Найти и установить esp32 by Espressif Systems

Выбрать плату:

Инструменты → Плата → ESP32 Arduino → ESP32 Dev Module

Дальше инструменты, внизу ищем Partition Scheme, ищем Minimal SPIFFS (1.9 MB че то там еще)

Во время самой прошивки, когда пройдет компиляция и начнет устанавливаться соединение с платой, может быть потребуется нажать и держать
кнопку boot на плате возле тайп си порта

Чтобы установить свой пароль вайфая, просто включите контроллер, подождите секунд 15-30, должна включиться точка доступа. Ищем её: Robot_Config_9 (цифра в конце - номер контроллера), пароль 12345678. Затем заходим на сайт 192.168.4.1 и вводим новые логин и пароль. Котроллер перезагрузится и по идее должен сразу подключиться к вашему вай фаю
